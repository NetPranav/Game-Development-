### 2. `ARREnemyAIController : AAIController` — C++ state machine, **no Behavior Tree, no AIPerception**
- States `enum class ERREnemyState : uint8 { Idle, Chase, Circle, Attack, Recover, Staggered, Dead }` stored on the controller (replication not required; AI is server-only).
- Think loop on a 0.1 s timer (weak capture, cleared in `OnUnPossess`/`EndPlay`), **not** `Tick`.
- Target acquisition: nearest living player pawn (`GetWorld()->GetPlayerControllers()` pawns, not `State.Combat.Dead`) within `AggroRange`; drop when beyond `LoseRange` or dead.
- Movement: `MoveToActor(Target, AcceptanceRadius=AttackRange*0.8, bStopOnOverlap, bUsePathfinding=true, bCanStrafe=true)` when a navmesh exists (`UNavigationSystemV1::GetCurrent(World)` and a valid nav data for the agent); **otherwise** steer directly with `Pawn->AddMovementInput(DirToTarget)` and a ground-snap-safe approach. Face the target (`SetFocus`/`SetControlRotation` smooth yaw, `bUseControllerRotationYaw=false` + `OrientRotationToMovement=false` while in combat range).
- Combat behaviour: Chase until `PreferredCircleRange`; then **Circle** (strafe left/right with `AddMovementInput` along the tangent, re-roll direction every 1.5–3 s) until the director grants an **attack token** (`URREnemyDirector::TryAcquireAttackToken(this)`), then close to `AttackRange` and **Attack**: `CombatComponent->RequestAttack(Light or Heavy)` once in range & facing within 25°; wait until `!IsAttacking()` (max 3 s safety) → **Recover** for `AttackCooldown` random in [min,max] → release the token → back to Circle/Chase. Heavy only if stamina allows (read `GetStaminaCost` usage from P4; it is fine to just attempt and let the ability refuse).
- Reactions: if `State.Combat.Staggered` → `StopMovement`, state Staggered until the tag clears; if the player is mid-attack and within 350 cm: roll `SidestepChance` for a sidestep (`CharacterMovement->Launch`/`LaunchCharacter` away at 600 cm/s, 0.25 s, with a 3 s per-enemy cooldown) or `BlockChanceWhenPlayerAttacking` for `SetBlocking(true)` for 0.8 s. Never act while Staggered/Dead.
- Expose `ERREnemyState GetState() const` and a debug draw (`rr.ai.debug 1` console var → on-screen state text above each enemy via `DrawDebugString`, `#if !UE_BUILD_SHIPPING`).
